# Lumen 功能手册

Lumen 是装在你 Windows 电脑上的一队 AI。你只跟 Lumen 说话，说人话就行；它会把活分给团队里最合适的成员，自己挑合适的工具，做完把结果交给你。写代码、查问题、剪视频、做 3D、做网页和 PDF、上网查资料、操作电脑，都能做。

## 1. 开始使用

- **需要什么**：Windows、Python 3.12，再加上一种 AI：Claude Code 或 Codex（装好后在终端里登录一次），或者一个 API 密钥（兼容 OpenAI 或 Anthropic 接口的服务都行）。
- **安装**：在 Lumen 文件夹里运行 `setup.ps1`（中文说明见 `安装环境.ps1`）。它会在这个文件夹里建一个 `.venv`，装好 Lumen 需要的包，不动你系统里的 Python。之后双击 `Lumen.cmd` 打开。
- **第一次打开**：欢迎页之后选界面语言、选一个工作文件夹，就能开始。模型可以以后在输入框下面换。
- **以后打开**：Lumen 会回到你上次的文件夹。左边栏可以切换文件夹、开新聊天、搜索聊天。

## 2. 发消息

- 在输入框里写你想做的事，按 Enter 发送。文件可以拖进来或粘贴进来。
- **语音输入**：点麦克风说话。说得随意也没关系，Lumen 会按意思理解，不会挑你的语法。
- **模型**：输入框下面选用哪个 AI（Claude Code、Codex 或你接入的服务里的模型），旁边是思考强度。模型完全由你决定，Lumen 不会自己换。
- **它不确定时会先问你**：如果它没把握弄懂你要什么，会弹出一个提问面板，每个问题都给好选项，你点选就行；不想答可以跳过，让它自己判断。
- **回答下面**：复制、记住、再答一次、改一改再问。回答做完后，过程步骤会折叠起来，只留最后的结果，点开能看每一步。

## 3. 批准方式

输入框下面选这个对话的批准方式，它决定 AI 做事之前要不要先问你：

| 批准方式 | 什么时候问你 |
|---|---|
| 完全放开 | 从不问，直接做 |
| 帮我审查 | 只在删除文件、以及用鼠标键盘操作电脑之前问 |
| 全部问我 | 每一个会改动东西的操作都先问 |

要问的时候，右下角输入框上方会弹出一张小卡片：一行说明要做什么，旁边是**同意**和**不同意**。点不同意只跳过这一个操作，其他的照常做。除此之外 Lumen 没有别的权限限制：电脑上的每个文件夹、每个盘都能用。

## 4. Lumen 团队

| 成员 | 负责 |
|---|---|
| Lumen | 总调度：和你对话，把活分下去，最后给你答复 |
| Spark | 写代码，也用各种制作工具 |
| Prism | 检查 |
| Torch | 实战：把程序真跑一遍 |
| Ray | 上网查资料 |
| Lantern | 管文件 |
| Beacon | 监督：复查别人的结果 |
| Iris | 操控电脑 |

每个成员都有自己的工作记忆，还能叫一次性的助手帮忙。成员之间能同时干活，互不重叠。

**Lumen 和你是平等的。** 它像一个能干的同事那样说话：你说错了它会直接指出来、讲清理由；它对的时候，你反复催它也不会改口，除非你给出理由。该你拍板的事，你定了，它就照着做好。

## 5. 自动用工具（不用 @）

直接说要做什么就行，比如“把这张图做成 PDF”“把这段视频剪成前 10 秒”“做一个红色的 3D 立方体”。Lumen 知道这台电脑装了哪些工具，会自己挑合适的，交给有这个工具的成员去做。

你也可以在输入框里打 @ 点名一个工具，那就只用你点名的那个。

| 工具 | 用来做 |
|---|---|
| CodeCut | 剪视频：剪切、拼接、字幕、配乐、导出 |
| Code3D | 3D 模型和场景，用你电脑上的 Blender，导出 GLB 和图片 |
| CodeSound | 音乐和音效 |
| CodePage | 网页 |
| CodeGame | 能玩的小游戏 |
| CodeDeck | 幻灯片和文档（PowerPoint、Word、PDF） |
| CodeData | 分析 Excel 和 CSV，报告里每个数字都查得到来源 |
| CodeCAD | 能 3D 打印的零件，尺寸以毫米为单位 |
| CodeLab | 看模型训练的日志和进度 |
| CodeTools | 几十个小工具：标志海报、流程图、二维码、字幕、配音、批量修图、整理文件等 |
| CodeFilm | 一句话出一段短片 |
| CodePDF | 图片转 PDF、合并、拆分、压缩、旋转、挑页 |

## 6. 右侧面板

- **工具窗口**：团队用到某个工具时，它会自动在右边打开，你可以看着它做。这个窗口是 AI 专用的：它在里面点、在里面打字，不占用你的鼠标键盘，你会看到一个蓝色的小鼠标在动。点窗口上的 × 就关掉。
- **浏览器**（Ctrl+Shift+B）：在这里搜索、打开网页，聊天里的网址也在这里打开。团队上网查资料时也会显示在这里。
- **终端**（Ctrl+J）：真的 PowerShell，就在当前文件夹里。团队运行的命令会用颜色显示在这里。

## 7. 长期记忆

- **AI 记得你**：每次新对话开始前，AI 会回顾以前的对话，把要点压缩成一份记忆：关于你（你是谁、怎么说话、喜欢什么、立过的规矩，所有项目共用）和这个项目（做过什么、定了什么、做到哪一步）。新对话一开始就带着它，所以你不用每次重新交代。
- **长短跟着历史走**：聊得少就几行，聊得多会长一些，平常在 5 万字以内，最多 8 万字左右；再长它会重新压缩，只减细节，不丢事情。
- **要等的时候会告诉你**：如果上一个对话的记忆还没整理完，新对话会显示“正在回顾以前的对话……”，最多等 90 秒。
- **你能看、能改、能清空**：在“设置 → 长期记忆 → AI 对你的记忆”里。改了的地方它以后照你改的来；清空后，以前的对话也不会再被拿来重新整理。
- 成员干活时还会记下值得记住的事实，下次自动想起；选一个嵌入模型后，还能按意思想起用词不同的旧结论。

## 8. 同时做好几件事

- 好几个对话可以同时进行，互不等待：一个对话在等你回答问题，另一个照样干活。
- 同一个文件夹可以开多个窗口（Ctrl+Shift+N）。
- 一个对话里学到的东西，别的对话下一次就知道（见第 7 节）。

## 9. 电脑操作

- 一开始就能用：截屏、鼠标、键盘、打开和关闭程序、终端，所有窗口都能用（Lumen 自己的窗口除外）。给程序名或完整路径，任何程序都能打开。
- 要不要先问你，看批准方式（第 3 节）。
- **操作方式**：一开始就在后台操作，不占用你的鼠标键盘；玩游戏这类需要真鼠标的，在“设置 → 电脑操作”里改成前台。
- **紧急停止**：按 `Ctrl+Alt+End`，或者把鼠标推到屏幕左上角。
- 不想让 AI 碰电脑：在“设置 → 电脑操作”里打开“禁止电脑操作”。

## 10. 需要管理员权限的时候

像 `C:\Windows`、`Program Files` 这类系统文件夹要管理员权限。遇到 Windows 说“拒绝访问”，AI 会以管理员身份重新运行那条命令，这时 Windows 会弹出它自己的确认窗口，由你决定是否允许。

## 11. 自动测试

在“设置 → 自动测试”里填上项目的测试命令（也可以点“自动检测”）。团队改代码时，系统会在开工前、每处修改后、交差前自动跑测试（不经过模型，不花 token）；谁改坏了原来能过的测试，当场指出。建议开工前先用 git 提交一次，随时能看到改了什么，也能撤回。

## 12. 界面语言

English、Français、Español、Deutsch、Italiano、Português、简体中文，一共 7 种，在“设置 → 外观”里切换，马上生效。右边的工具窗口也跟着换。AI 用你写消息的语言回答。

## 13. 设置一览

- **服务与密钥**：接入任意多个 AI 服务。密钥只存在 Windows 凭据管理器里，不写进配置文件。
- **AI 模型**：每个成员用哪个服务的哪个模型、想得多深、出错时换哪个备用模型。
- **长期记忆**：回忆开关、AI 对你的记忆、按意思回忆。
- **自动测试**、**电脑操作**：见上面。
- **外观**：语言、壁纸、字体大小、强调色等，改了立刻生效。
- **用量**：今天、七天和全部用了多少。
- **功能手册**：就是这一页。

## 14. 顺手的小功能

- **Ctrl+K**：一个框找到一切：聊天、页面、操作；打两个字以上，连聊天里说过的话也能搜到。**Ctrl+/** 看全部快捷键。
- **Ctrl+N** 新聊天，**Ctrl+B** 收起或打开左边栏，**Ctrl+F** 在聊天里查找，**Ctrl+,** 打开设置。
- **聊天右键**：重命名、导出为 Markdown、从列表里收起（不删除）。
- **常用语**：写好一段话按 Ctrl+S 存为常用语，在空的输入框里打 / 调出。没发出去的话，关掉窗口也留着。
- **做完提醒**：窗口不在最前面时，回答做完了任务栏会亮，右下角有提醒。
- **浏览器**：星星收藏这一页，Ctrl+Shift+T 找回关掉的标签页，气泡把这一页发给 Lumen。
- **终端**：在输出上右键，把选中的或最近的输出发给 Lumen。

## 15. 安全与隐私

- 模型全部由你选择，Lumen 不会自己换。
- 你的对话、记忆、日志都保存在你自己的电脑上（`~/.codedoctor` 文件夹）。
- 密钥只在 Windows 凭据管理器里；记忆里不会存密钥。
- 付款、登录这类事情 AI 不会替你做。

## 16. 小贴士

- 说得越具体，第一次就越接近你要的；不具体也没关系，它会先问你。
- 想快一点、省一点，就选小一点的模型或低一点的思考强度；难的活再换大的。
- 遇到闪退，把 `~/.codedoctor/crash.log` 发给开发者。
