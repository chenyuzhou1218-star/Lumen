# ADR 0015：四种协作方式与玻璃界面

- 状态：提议（用户自己测试）
- 日期：2026-10-27
- 作者：Claude
- 用户要求：ChatGPT 那份（桌面快捷方式运行的 Codex 工作目录 business-cluster-backend）开场动画好看，进去之后的界面丑。把动画和玻璃风格搬到这份代码，用这份的页面结构重做外观；多 AI 集群全部做出来，按 ChatGPT 的风格接着做。

## 外观（搬自 ChatGPT 的 studio 版本）

- `desktop/liquid.py`（丝绸 / 极光壁纸、玻璃面板、医疗十字、玻璃滑块）和 `desktop/motion.py`（入场动效）原样搬入，文件头注明来源。
- `desktop/welcome.py`：手写问候动画（十种语言）原样搬入；外面的卡片改用中文和本项目的控件。
- 窗口最外层是壁纸，开场动画和主界面是叠在上面的两个画面；动画写完、或点“进入 / 跳过动画”后滑入主界面。测试和脚本默认不播放。
- 主题（`theme.py`）改为冷色玻璃：侧边栏、卡片、输入框、按钮、菜单都是半透明白色叠在壁纸上，强调色改为蓝色。调色板 `C` 仍是不透明的十六进制（QColor 要用），半透明只写在样式表里。
- 设置新增“外观”标签：壁纸、启动时播放开场动画、减少动态效果、立即重播。只影响这台电脑，存在 `~/.codedoctor/ui.json`，改了立即生效。

## 四种协作方式（来自 ChatGPT 的 cluster/topology，接进本项目）

| 方式 | `cluster.mode` | 结构 | 人数 | 谁接你的任务 |
|---|---|---|---|---|
| 单人助手 | `basic` | 1 个单 Agent | 1 | 单 Agent |
| 双人互检 | `dual` | 1 个执行者 + 1 个监督者，没有首脑 | 2 | 执行者 |
| 协作小队 | `small` | 2 个首脑 + 执行者，每 2 个执行者共用 1 个监督者 | 5–38（每次加 3） | 调度首脑 |
| 双首脑集群 | `advanced` | 2 个首脑 + 执行者，每个执行者有自己的监督者 | 4–40（每次加 2） | 调度首脑 |

- 旧值 `collab` 仍可读取，等于“双首脑集群，一次一个子任务”。
- 监督者可以同时监督多个执行者：`supervises_workers`（字段名和 ChatGPT 那份一致，它的配置文件在这里也能用）。复查任务按 `guardian_for` 找到这个监督者；同模型提醒、Agent 详情、集群页都按“它监督的所有执行者”处理。
- 配置校验按方式检查结构：双人互检必须正好 1 个执行者和监督它的 1 个监督者、没有首脑；协作小队每个监督者正好看 2 个执行者；双首脑集群每个监督者正好看 1 个；每个执行者都正好有一个监督者。单 Agent 不算在集群的 40 个里。
- 双人互检里任务直接交给执行者：它像单 Agent 一样自己决策发现的异常（`decide_anomaly` 只允许决策它自己接的调查），交付前同样有交付审查和未决策异常拦截；做完后它的监督者自动复查。
- 协作小队和双首脑集群都可以“按需并行”；持续监控（双首脑推演）可以开，频率、每轮步数、每轮和每小时 token 上限都能在页面上改（ChatGPT 那份的高级设置）。

## 编队（`codedoctor/topology.py`）

`draft(raw, mode, count)` 只改要保存的配置，不会立即生效：

- 按角色依次沿用已有的 Agent（id、模型、预算、参数都保留），多出来的从配置里去掉（历史记忆保留）；
- 新加的 Agent **没有模型**，由用户选（页面上可以一次给多个选同一个，默认填上现有执行者的模型作为建议）；
- 单 Agent 在每种方式下都保留；选单人助手时如果一个都没有，会加一个没有模型的 `doctor`。

## 界面

- 调度设置改为“选择协作方式”：四张玻璃卡片（带小结构图：首脑、执行者、监督者用不同颜色）、总人数滑块、一句话说明、并行和持续监控选项、持续监控的频率和预算、四种方式对比表。
- 集群页按当前方式画结构：协作小队每组是两个执行者共用一个监督者。
- 输入框的模式按钮显示“单人助手 / 双人互检 / 协作小队 / 双首脑集群”中当前可用的。

## 没有做

- ChatGPT 那份的首次设置向导（语言、选择协作方式、连接 AI 的多步向导）还没搬；本项目在“设置”里完成同样的选择。
- 工作台（文件、后台进程、浏览器、文档生成、MCP、定时任务）、像 ChatGPT 那样的聊天、上传文件和图片、语音输入：按用户定的顺序接下来做。
- 按用户要求没有跑自动测试；做了编译、导入检查，以及六种方式 / 人数的配置校验和界面渲染检查。
