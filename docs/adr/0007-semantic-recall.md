# ADR 0007：按意思回忆（M6 向量检索）

- 状态：提议（待审查）
- 日期：2026-10-25
- 作者：Claude
- 用户要求：先做 M6。
- 承接：[ADR 0003](0003-long-term-memory.md)（两层记忆）、[ADR 0006](0006-memory-claim-status-and-coupling-recall.md)（主张状态与耦合回忆）

## 要解决的问题

trigram 文字检索只能找到和问题有相同字词的笔记。评测基线里，用英文问"match reward paid twice"，而相关笔记是中文"比赛奖励会到账两次"，第一条正确笔记只排第 5（RR 0.2）。同样，同义词、换了说法的问题也找不到。

## 决定

### 模型由用户指定

- 项目配置新增可选的 `[memory.embedding]`：`endpoint`、`model`、`min_similarity`（默认 0.35）。**不配置就没有语义检索**，系统不会自己挑模型，也不会自动换模型。
- 只接受 OpenAI 兼容接口（`/v1/embeddings`），覆盖 Ollama、OpenAI、硅基流动等。Anthropic 接口没有嵌入功能，配置校验时直接拒绝，并说明原因。
- 桌面"模型与 API"页新增"长期记忆：按意思回忆（可选）"：服务下拉框里只有 OpenAI 兼容的服务，外加"不使用"；模型名由用户填写或从建议里选，默认什么都不选；"测试"按钮只发送两句固定的测试文字。

### 数据级别

- 笔记新增"敏感度至少等于它的来源"规则：
  - `remember` 写的笔记，带上当前任务上下文的数据级别；
  - 任务结束写的摘要和主张笔记，带上该任务见过的最严格的数据级别；
  - 没有标注的笔记，按项目代码的级别（`code_data_class`）算。
- 只有数据级别不超过嵌入服务 `max_data_class` 的笔记才会被发送。超过的不发，在库里留一个"不可发送"标记，这条笔记永远不会因为意思相近被找到，但文字和耦合回忆仍然能找到它。
- 查询文字同样受这个规则约束：任务上下文里有机密数据时，如果嵌入服务只允许 internal，查询本身就不发送。

### 存储与检索

- 新表 `note_vectors`（数据库 schema v5），以 `"<服务>/<模型>"` 为键。**不同模型的向量从不混用**，换了模型会全部重新生成。
- 向量存成单位长度的 float32，检索时对读者可见的笔记做点积。不引入 numpy：Python 3.12+ 用 `math.sumprod`，几千条笔记在 1 秒以内；更大的规模以后再说（见"不在本次范围"）。
- 何时生成向量：
  1. 后台服务里有一个专门的循环，空闲时生成，新笔记优先；
  2. 每次检索前先补一小批（32 条），刚写下的笔记马上就能被找到。
- 打分：余弦相似度低于 `min_similarity` 的算 0，高于的线性映射到 0–1，乘以权重 0.6，加到原来的分数上。也就是说，**语义分是叠加，不替代文字、耦合和主张状态的打分**。
- 召回结果显示 `(close in meaning to the query: 0.72)`；HTTP / 命令行输出新增 `meaning` 字段。

### 失败处理

嵌入服务出错时，召回照常进行，只是退回到文字 + 耦合，原因记在 `services.vectors.last_error`。后台循环失败后隔 60 秒再试，不会切换到其他模型。

### 调用路径

任务开始时的自动回忆、`recall` 工具、HTTP API、命令行都改走同一个异步函数 `related.recall_async`。`recall` 工具因此改成异步工具（在事件循环上运行，不再放到线程里）。

## 评测

- `codedoctor bench --embedding-config <你的配置文件>` 会用你在配置里指定的嵌入模型多跑一行"+M6 按意思回忆"。**样例场景里的笔记会发送到那个服务**，所以只在你明确传入时才运行。
- 不传这个参数时，报告里写"M6 未评测"，不调用任何模型。
- 测试里用一个"概念嵌入器"代替真实模型：同一概念的中英文词映射到同一维度。它只验证机制，比如英文问题能找到中文笔记、机密笔记不外发、故障时退回文字检索；**不代表任何真实模型的效果**。真实效果要等你选定模型后跑评测才知道。

## 不在本次范围

- 向量索引（ANN）：笔记上万条后，逐条点积会变慢，到时再加。
- 按模型自动校准 `min_similarity`：目前是固定默认值加手动配置，要用评测来调。
- 笔记的分块：只取前 2000 字生成向量，长摘要的后半部分不参与语义检索。

## 测试

- `tests/daemon/test_memory_vectors.py`：10 项，包括配置校验、请求格式、测试按钮只发固定文字、跨语言召回、文字召回不受影响、机密笔记与机密查询不外发、故障退回、换模型重新生成、`remember` 记录数据级别，以及后台生成向量和任务开始时使用。
- `tests/daemon/test_desktop.py`：桌面页选择、保存、清除嵌入模型。
- `tests/daemon/test_bench.py`：M6 这一行只在提供用户配置时才运行。
- 全部 446 项通过。脚本模型基线的分数与之前完全相同。
