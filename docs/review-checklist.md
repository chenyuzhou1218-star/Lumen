# 复查清单：每做完一大块，照着逐条在真实 Lumen 里复现

用法：另一个 AI（或用户自己）打开真实的 Lumen 窗口，从上往下一条一条做。每条写下"做了什么、看到了什么、对不对"，有截图的附截图。不要跳过，不要只看代码就下结论。
怎么做、报告写到哪里，见 `docs/review-guide-for-ai.md`。

## A. 花钱（最先查，任何一条不对都是严重问题）
1. 输入框右下角一直显示当前的模型和思考档位；鼠标停在上面能看到完整名字。
2. 选一个模型（例如 Codex · GPT-6-Luna · Low），发一个问题。回答出来以后，输入框里还是同一个模型和档位，没有变成别的。
3. 回到"新聊天"：输入框里是刚才选的模型。
4. 两个对话用不同的模型，来回切换：每个对话显示的都是它自己最后一轮用的模型。
5. 关掉 Lumen 再打开：新聊天里是最后一次选的模型。
6. 从没选过模型时（可以删掉 `~/.codedoctor/ui.json` 里的 `last_pick` 来模拟），输入框不替你填模型；直接发送会被拦下，并提示"先在输入框右下角选一个模型。"
7. 设置 → 用量 → "每个问题最多用多少新 token"：调到最小（5 万），再发一个大问题。用到上限时问题会停下，对话里出现"到了你设的上限……所以停下了"，并有"接着做"和"改上限"两个按钮。
8. 问题进行中，回答上方显示"已用 X / 上限 Y"，数字在涨，快到上限时变色。
9. 以往同类问题平均花得比上限多时：发送前先弹出提示，问"先不发 / 照样发"。
10. 团队成员、一次性助手、自动复查用的都是你选的模型。看"详细 → 工作区一览 → 时间线"和每个成员那一栏，不能出现别的模型。
11. "继续执行"和"再答一次"用的还是原来的模型。

## B. 外壳和对话
12. 新聊天、搜索聊天（标题能搜到，聊天内容里的词也能搜到）、插件、设置，每个入口都能打开。
13. 侧栏里的聊天：右键和 ⋯ 菜单里的置顶、重命名、导出为 Markdown、从列表里收起都能用；Ctrl+K 里能把收起的放回来。
14. Ctrl+B 收起侧栏，再展开；把窗口拉窄到 800 像素以下，侧栏变成一列图标，点开时浮在页面上面。
15. 任何窗口宽度下，输入框底部的按钮都在同一行，不换行，不被截断。
16. 对话页：标题点一下能重命名；Ctrl+F 能查找；代码块的"复制"能用；链接在右边的浏览器里打开。
17. 回答下面的"详细"展开后能看到结论、改动清单、异常、电脑操作（有的话）；"工作区一览"里每个标签都能打开，改动有 diff，"撤回"会先问你。
18. "记住"、"再答一次"、"改一改再问"都能用。

## C. 设置
19. 服务与密钥：添加、编辑、测试连接、删除密钥、删除服务；密钥要按"保存"后才写进凭据管理器，保存前关掉窗口什么都不留。
20. AI 模型：改服务、模型、思考档位、备用模型，保存后重启生效。
21. 长期记忆、结论与记忆、功能手册、用量都能打开，内容正确。
22. 外观：浅色、深色切换时所有页面一起变，终端也一起变；字号、圆角、聊天宽度、发送键、时间、token 显示，改了立刻生效。

## D. 右边的浏览器和终端
23. 侧栏顶上的两个小按钮各自打开或关闭浏览器、终端；两个都开时上下分，中间的线能拖动。
24. 浏览器：起始页、地址栏、前进后退刷新、多标签、收藏、把这一页发给 Lumen；深色模式下外框是黑的。
25. 终端：打开就能看到 PowerShell 的启动信息、提示符和光标；能输入命令、Tab 补全、方向键、Ctrl+C；右键能把内容发给 Lumen。

## E. @ 工具和首次使用
26. @CodeCut 等工具：上方出现工具区，"允许"按钮看得清，工具窗口占大部分高度，分隔线可拖动并会记住。
27. 第一次打开（删掉 `~/.codedoctor/setup.json` 来模拟）：欢迎动画、区域和语言、选择 AI、开始使用；换语言后整个向导换成新语言。

## F. 每条的结论
每条写"通过 / 不通过 / 没法测（原因）"。不通过的写清楚复现步骤和看到的样子。
