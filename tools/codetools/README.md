# CodeTools

**打开：** 双击 `D:\CodeDoctor\CodeTools.lnk`，或在 Lumen 左边点“插件”。

一个窗口里的几十个小工具：标志和海报、动画、流程图、二维码、电子书、字幕、配音、批量修图、PDF、整理文件、备份、全文搜索、接口测试、数据库、日志分析、精确计算、电路、物理模拟、排期、世界地图、数值平衡、短片合成等等。

都在本机运行，不用账号，不用下载。整理和移动文件前会先给你看计划，任何插件都不会删除你的文件。

在 Lumen 里输入 `@CodeTools`，AI 也能用它们。

## 加一个插件

在 `plugins/` 里写一个文件就行，表单窗口和 AI 工具都会自动有。每个动作都带一个样例：

```bash
python codetools.py check
```

会把所有插件在样例上实际跑一遍。
