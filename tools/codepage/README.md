# CodePage

**打开：** 双击 `D:\CodeDoctor\CodePage.lnk`，或者本文件夹里的 `CodePage.lnk`。

拖一拖就能做网页，代码自动生成。完全免费，不用账号，不用联网，拖拽时不调用任何模型。

- **左边是组件，六百六十多个**：导航栏、首屏、特点、数字、卡片、图文、图片墙、评价、团队、价格表、问答、步骤和时间线、号召、联系、表单、互动、标志墙、提示条、文字、按钮、幻灯片、页脚……一百六十多种排法，大多数有常规、灰底、反色、主色、渐变五种样子，都跟着你选的配色走。上面可以按分类、按样子筛，也可以搜。
- **会动的组件**：标签切换、左右滑动、滚动文字、前后对比（拖着看）、数字滚动、轮换词、翻转卡片、展开图片、跟随光晕；任何组件都能设“出现”方式（上浮、淡入、放大、左入、右入），滚到那里时出现。
- **幻灯片（PPT）**：拖一个“幻灯片”进来就是一组能翻页的演示。编辑时每一页都摆出来，任何组件都能拖进任何一页；右边可以加页、删页、调顺序，新的一页可以直接选封面、目录、要点、图文、大数字、柱状图、时间线、对比、表格、团队、流程、代码、结束页。导出的网页一次放一页：方向键、按钮、手指滑都能翻，⛶ 全屏放映，打印时一页一张，能存成 PDF。
- **中间是页面**：拖进去就是真实的网页。可以切换电脑、平板、手机宽度，手机上的排版是真的会变。
- **右边是属性**：选中什么就改什么：文字、图片、颜色、间距、宽度、高度、圆角、阴影、内容竖直放哪里、怎么出现。
- **一键导出**：一个 `index.html`，双击就能打开，也能直接放到任何网站空间。“看代码”可以随时看到生成的 HTML 和 CSS。

搜索栏是能用的：可以跳到搜索引擎或你自己的网站，也可以只搜这一页。

- **层级、模板、外观**：左边的竖条切换。层级是整页的树，模板有十七个（演示文稿、产品发布、手机应用、餐厅小店、工作室、活动报名、博客文章……），外观里换配色、圆角和字体。
- **画布上直接改**：选中的组件上面有一排小按钮（上移、下移、选外面那层、复制、删除）。右边的把手拖宽度，下边的拖高度，右下角的两样一起拖；拖的时候旁边显示尺寸，往上拖到比内容还矮就回到自动高度。
- **快捷键**：Ctrl+Z / Ctrl+Y 撤销重做，Ctrl+D 复制一份，Alt+↑↓ 上下移，Delete 删除，`/` 找组件。

## 前端拖好了，后端交给 AI

点右上角的 **写后端**：CodePage 读一遍页面，把要后端处理的地方列出来（表单和它们的字段、还没有去处的按钮和链接），你可以再补几句要求。在 CodePage 窗口里点“交给 Lumen”，需求会写进这个文件夹的 `BACKEND.md`，再交给 Lumen 的团队去写 `backend/`；用浏览器打开时可以复制需求，贴到 Lumen 里。需求里写明了：能用 Python 自带的库就不装新东西，要装先问你，数据先存在本地，不接任何收费服务。

## 打开

不想开窗口的话，用 Chrome 或 Edge 直接打开 `builder/index.html` 也一样能用，只是保存和导出变成下载文件。

## 给 AI 用

在 Lumen 里输入 `@CodePage`。AI 和你改的是同一个 `page.json`，窗口会跟着更新。

```bash
python codepage.py init mysite
python codepage.py build mysite --pictures
```

写法见 [AI_GUIDE.md](AI_GUIDE.md)。

## 组件是怎么来的

`builder/components.js` 是生成的，不要直接改：原来的六十个在 `library/core.json`，新的按种类写在 `library/families/` 里，每种排法写一次，五种样子由 `library/kit.py` 里的样式变量自动配出来。改完运行：

```bash
python library/make.py
python -m unittest discover -s tests
```

`library/sheet.py` 能把一组组件按真实的网页渲染成图片，方便一个个看。测试会核对窗口和命令行两边生成的网页逐字一致，并用真实鼠标走一遍拖高度、幻灯片、筛选这些操作。
